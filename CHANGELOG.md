# Versions

## 1.0.0
Première version : bulle déplaçable avec compteur, fenêtre déplaçable, dictée et écoute continue, écran noté automatiquement, suivi À traiter / Corrigées / Toutes, vérification une par une, version de correction et réouverture, file d'attente hors ligne ; outils Capture (zones à main levée avec consigne), Élément, Texte, Mesure ; contexte technique joint à chaque note ; export texte pour Claude, ZIP et JSON ; tableau de bord multi-projets ; onglet Interface (apparences de fermeture avec aperçus, façons de fermer la fenêtre, icônes déplaçables et masquables, éléments masqués, taille de la bulle) ; couleurs adaptées à l'appli (fond, couleur principale, police) ; outil Texte compatible avec la sélection native du téléphone. Fenêtres des outils déplaçables qui retiennent leur place ; bouton « Vérifier une par une » en barre fixe en bas de la liste ; « ‹ Notes » et « ‹ Précédente » en haut de la vérification ; modification d'une note sur toute la largeur ; zone de texte de taille fixe dont le texte défile pour garder la fin visible pendant la dictée ; notes réordonnables par appui long (priorité reprise dans l'export) ; date et heure en gras.
