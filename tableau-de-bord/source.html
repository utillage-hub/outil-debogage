Notes

Chaque appli qui embarque l'outil garde ses notes dans sa propre base. Pour les réunir ici : dans l'appli, bulle › ⚙ › « Pour le tableau de bord » (ou le ZIP), puis Importer un export ou glisse le fichier sur cette page. Un nouvel import du même projet met les notes à jour, sans doublons. Les notes prises sur ce tableau de bord avec sa propre bulle apparaissent dans le projet « tableau-de-bord ».
